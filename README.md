# NamaAI — مستشار مالي ذكي للمنشآت الصغيرة

مشروع هاكاثون أمد 2026 — مسار الذكاء الاصطناعي التوليدي للتقنية المالية.

## الفكرة
مستشار ذكي مدعوم بالذكاء الاصطناعي داخل بوابة مصرف الإنماء للمنشآت الصغيرة (SMEs)،
يحلل البيانات المالية، يتنبأ بالعجز النقدي قبل حدوثه بحتى 30 يومًا، ويقترح حلولًا
تمويلية فورية مخصصة.

## البنية المعمارية

```
محرك القواعد الحتمي (analysis.js)          الطبقة التوليدية (ai.js)
├─ يحسب: الصحة المالية، التنبؤ 30      ├─ يرسل نفس الأرقام لـ Claude API
│  يوم، نسبة التحصيل من البيانات        ├─ يولّد توصية بلغة طبيعية +
│  الفعلية، مبلغ التمويل المقترح        │  خطوات عملية مخصصة
└─ قابل للتفسير الكامل، كل رقم          └─ طبقة إضافية فوق القرار الحتمي،
   له معادلة واضحة                        مو بديل عنه
```

القرار المالي (المبلغ، نوع التمويل) **حتمي ومبني على قواعد واضحة** — والذكاء
الاصطناعي التوليدي (Claude) **يشرحه بلغة طبيعية ويقترح خطوات إضافية**، مو
مصدر القرار نفسه. هذا الفصل مقصود: يخلي القرار المالي قابل للتدقيق والمراجعة
(مهم جدًا لأي نظام مصرفي)، بينما الذكاء الاصطناعي يضيف قيمة حقيقية بالتواصل
والتحليل السياقي.

## ⚠️ ملاحظة مهمة عن البيانات
البيانات المستخدمة في هذا الـ MVP **اصطناعية بالكامل**، وتُولَّد **حيًّا من
داخل التطبيق نفسه** (صفحة "مصدر البيانات" ← زر "توليد بيانات اصطناعية
جديدة") بسبب استحالة الوصول لبيانات عملاء حقيقية لأسباب تتعلق بسريّة البيانات
المصرفية.

قاعدة البيانات **مبنية أصلًا لتخدم عدد غير محدود من المنشآت** (كل جدول
مرتبط بـ `company_id`) — تمامًا زي أي بنك يخدم آلاف الـ SMEs. الانتقال لبيانات
حقيقية يعني استبدال منطق `server/seed.js` بمصدر بيانات حقيقي (Open Banking
API مثلًا) يكتب لنفس الجداول، **بدون أي تعديل على منطق التحليل أو التنبؤ أو
واجهات الـ API**.

**نسبة التحصيل** (المستخدمة بمعادلة التنبؤ) **تُحسب فعليًا من تاريخ الفواتير**
(مدفوعة مقابل متأخرة)، مو رقم ثابت مفترض — كل ما تراكمت بيانات أكثر، صارت
النسبة أدق تلقائيًا.

## الإعداد

### 1. تثبيت الحزم
```bash
npm install
```

### 2. مفتاح Claude API (اختياري لكن موصى به بشدة)
انسخ `.env` (موجود مسبقًا بالمشروع) وعبّي `ANTHROPIC_API_KEY` بمفتاحك من
[console.anthropic.com](https://console.anthropic.com):
```
ANTHROPIC_API_KEY=sk-ant-...
```
**بدون المفتاح، المشروع يشتغل كامل عدا زر "توليد تحليل ذكي عبر Claude API"**
(يظهر تحليل مبني على القواعد بدل النص المولّد بالذكاء الاصطناعي).

### 3. تشغيل الباك إند (نافذة طرفية أولى)
```bash
npm run server
```
عند أول تشغيل، يتولد `server/namaai.db` تلقائيًا ويُعبّى ببيانات اصطناعية +
مستخدم دخول تجريبي. السيرفر يشتغل على http://localhost:3001

### 4. تشغيل الفرونت إند (نافذة طرفية ثانية)
```bash
npm run dev
```
افتح الرابط اللي يطلع (عادة http://localhost:5173)

### 5. تسجيل الدخول
بيانات تجريبية معبّأة تلقائيًا بشاشة الدخول:
- **البريد**: `demo@namaai.sa`
- **كلمة المرور**: `namaai2026`

## الأمان
- كلمات المرور مشفّرة بـ `scrypt` (لا تُخزّن كنص صريح أبدًا)
- الجلسات عبر توكن عشوائي 256-بت، تنتهي صلاحيتها تلقائيًا بعد أسبوع
- كل مسارات الـ API (عدا تسجيل الدخول وأداة تجهيز الديمو) تتطلب جلسة صالحة
- CORS مقيّد لعنوان الفرونت إند المحدد فقط (`CORS_ORIGIN` بملف `.env`)
- مفتاح Claude API يُقرأ من متغير بيئة فقط — لا يُكتب بالكود أبدًا، و`.env`
  مُستثنى من Git

## نقاط REST API الرئيسية

| المسار | الوصف | يتطلب دخول |
|---|---|---|
| `POST /api/auth/login` | تسجيل الدخول | لا |
| `GET /api/datasource` | حالة مصدر البيانات | لا |
| `POST /api/datasource/generate` | توليد بيانات اصطناعية جديدة | لا |
| `DELETE /api/datasource` | مسح كل البيانات | لا |
| `GET /api/company` | بيانات الشركة | نعم |
| `PUT /api/company` | تحديث بيانات الشركة | نعم |
| `GET/POST/PUT/DELETE /api/invoices` | إدارة الفواتير | نعم |
| `GET /api/analysis` | كل المؤشرات + التنبؤ 30 يوم | نعم |
| `POST /api/analysis/simulate` | محاكاة "ماذا لو" (نفس محرك التحليل الحقيقي، بدون حفظ) | نعم |
| `POST /api/analysis/ai-insight` | توليد تحليل ذكي فعلي عبر Claude API | نعم |
| `POST /api/funding/request` | تسجيل طلب تمويل فعلي بقاعدة البيانات | نعم |
